# 操作说明

## 一、环境准备

需要 Node.js 18+（建议 20+）。

首次运行安装依赖与浏览器：

```powershell
npm install
npx playwright install --with-deps chrome
```

## 二、配置鉴权 Token

启动任务需要鉴权。通过环境变量 `API_TOKEN` 设置访问令牌（不设则默认 `dev-token`，仅供本地开发）。

PowerShell 设置示例：

```powershell
$env:API_TOKEN = "你的强随机令牌"
npm start
```

## 三、启动服务

```powershell
npm start
```

看到 `RPA 服务已启动: http://localhost:3000` 即成功。浏览器打开该地址。

开发模式（改动自动重启）：

```powershell
npm run dev
```

## 四、页面操作流程

1. 在页面顶部填写 **访问令牌**（与 `API_TOKEN` 一致）。
2. 选择 **目标站点**，填写 **用户名 / 密码**。
3. 点击 **开始执行 RPA**。此时会弹出一个 Chromium 窗口，可实时观察自动化操作。
4. 当流程运行到短信验证环节，页面出现 **验证码输入框**：
   - 输入收到的短信验证码，点击 **提交验证码**（或按回车）。
5. 验证码正确 → 流程继续执行后续操作，直到完成。
6. 验证码错误 → 页面提示错误并重新弹出输入框，可重试（默认最多 3 次）。

执行过程中的所有日志会显示在页面底部「执行日志」区。

## 五、接入你自己的目标网站

编辑 [../src/siteConfigs.js](../src/siteConfigs.js)，**无需改动其他代码**。

### 步骤 1：录制获取选择器

```powershell
npm run codegen -- https://你的目标站点/login
```

手动操作登录一遍，Playwright 会自动生成对应的选择器代码。

### 步骤 2：编写配置

参考示例，把选择器换成真实值，并在验证码环节插入 `waitSmsCode`：

```js
export const siteConfigs = {
  mySite: {
    url: "https://your-site.com/login",
    headless: false,
    steps: [
      { action: "goto" },
      { action: "fill", selector: "#user", valueRef: "username" },
      { action: "fill", selector: "#pass", valueRef: "password" },
      { action: "click", selector: "#login" },

      { action: "waitForSelector", selector: "#otp" },

      // 短信验证码：支持错误重试
      {
        action: "waitSmsCode",
        selector: "#otp", // 验证码输入框
        submitSelector: "#otp-submit", // 提交按钮
        successSelector: "#dashboard", // 出现则视为成功
        errorSelector: ".otp-error", // 出现则视为验证码错误
        maxRetries: 3,
        timeout: 180000,
      },

      // 后续业务操作
      { action: "waitForSelector", selector: "#dashboard" },
      { action: "screenshot", path: "done.png" },
    ],
  },
};
```

### 支持的 action 一览

| action            | 参数                           | 说明                         |
| ----------------- | ------------------------------ | ---------------------------- |
| `goto`            | `url?`                         | 打开页面（默认用配置根 url） |
| `fill`            | `selector`, `valueRef`/`value` | 填入文本                     |
| `click`           | `selector`                     | 点击                         |
| `waitForSelector` | `selector`, `timeout?`         | 等待元素出现                 |
| `waitForUrl`      | `url`, `timeout?`              | 等待 URL 匹配                |
| `waitSmsCode`     | 见下                           | 挂起等验证码，支持重试       |
| `sleep`           | `ms`                           | 固定等待                     |
| `screenshot`      | `path?`                        | 截图                         |

`waitSmsCode` 参数：

| 参数              | 必填 | 说明                                        |
| ----------------- | ---- | ------------------------------------------- |
| `selector`        | 是   | 验证码输入框                                |
| `submitSelector`  | 是   | 提交按钮                                    |
| `successSelector` | 否   | 出现则判定成功                              |
| `errorSelector`   | 否   | 出现则判定验证码错误并重试                  |
| `maxRetries`      | 否   | 最大重试次数（默认 3）                      |
| `timeout`         | 否   | 每次等待用户输入的超时毫秒数（默认 180000） |

## 六、常见问题

- **浏览器没弹出**：确认配置里 `headless: false`。
- **选择器找不到元素**：用 `codegen` 重新确认，或增大 `waitForSelector` 的 `timeout`。
- **一直提示验证码错误**：检查 `errorSelector` 是否匹配了目标站点真实的错误提示元素。
- **等待验证码超时**：默认 3 分钟，可调大 `waitSmsCode` 的 `timeout`。
- **令牌校验失败(401)**：确认页面填写的令牌与启动时的 `API_TOKEN` 一致。

## 七、安全提醒

- 生产环境务必启用 HTTPS / WSS，并使用强随机 `API_TOKEN`。
- 登录凭据不要硬编码或提交到仓库。
- 确认对目标站点执行 RPA 已获得合法授权。
